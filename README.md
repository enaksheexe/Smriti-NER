## About the Project

**Smriti-NER** is an accessible, interactive cognitive gaming and memory assistance platform designed specifically for elderly individuals living with dementia. Tailored to reflect the rich cultural context of **North East India**, the platform provides engaging mental exercises, familiarity-driven memory aids, and an intuitive interface that supports both seniors and their caregivers in daily cognitive care.

### Live Deployment
Explore the live application here: **[https://enaksheexe.github.io/Smriti-NER/](https://enaksheexe.github.io/Smriti-NER/)**

---

##  Key Features

*  **Cognitive Games:** Custom-built memory, pattern recognition, and focus-enhancing exercises designed for gentle mental stimulation.
*  **Localized Context:** Culturally relevant themes, visuals, and references tailored specifically for seniors in North East India.
*  **Senior-Friendly Accessible UI:** High-contrast visuals, large typography, and clutter-free navigation designed for ease of use by elderly users.
*  **Progress & Memory Tracking:** Simple, encouraging feedback metrics to help users and caregivers monitor daily engagement and cognitive recall.
*  **Responsive Design:** Works seamlessly across desktops, tablets, and mobile devices.
